# If someone copies 一夜狼人殺 One Night Wolf

The game is © 2026 Matthew Wong, all rights reserved (see `LICENSE`). If you find a copy online:

1. **Save evidence**: the copy's web address, screenshots, and the date you found it.
2. **Find the host**: the address usually shows it (`github.io` = GitHub, `netlify.app` = Netlify,
   `vercel.app` = Vercel, `onrender.com` = Render). For other addresses, look the domain up on
   https://lookup.icann.org to see who hosts it.
3. **Send a takedown (DMCA) notice** using the host's own form:
   - GitHub: https://support.github.com/contact/dmca-takedown
   - Netlify: https://www.netlify.com/legal/dmca/ (or email the address on that page)
   - Vercel: https://vercel.com/legal/dmca-policy
   - Render: https://render.com/dmca
   - Google (to remove it from search results): https://reportcontent.google.com
4. Most hosts act within a few days. Keep a copy of what you sent.
