# 帳戶紀錄設定（Google 登入 + 訪客紀錄 + 擁有者監察）

未設定之前，遊戲照常運作（冇登入、冇紀錄）。設定好之後：
- 主頁有「用 Google 登入」；唔登入就以訪客身份玩（一樣會記錄）。
- 所有紀錄寫入你 Google Drive「一夜狼人殺」資料夾入面嘅試算表「一夜狼人殺 帳戶紀錄」：
  - **帳戶**：Google ID｜Email｜暱稱｜勝｜負｜總局數｜勝率｜最後遊戲｜最後登入｜建立日期｜登入次數
  - **登入紀錄**：每次 Google 登入、返回、訪客到訪（同一人 30 分鐘內只記一次）
  - **對局**：每局完場一行（房主回報）
  - **戰績**：每個已登入玩家每局一行（有電腦玩家嘅局唔計勝負）
  - **房間**：開緊嘅房間（房主每分鐘更新）
- 用你自己 Google 帳戶登入後，主頁同帳戶視窗會出現「📊 擁有者監察」：進行中房間、每日使用量圖、登入紀錄、最近對局。

## 1. Google 登入用戶端 ID（同月夜狼人殺共用即可）
1. console.cloud.google.com →（月夜狼人殺嘅專案）→ API 和服務 → 憑證。
2. 打開月夜狼人殺用緊嘅「OAuth 2.0 用戶端 ID」（網頁應用程式）。
3. 「已授權的 JavaScript 來源」加：`https://one-night-wolf-w1e3.onrender.com` → 儲存。
4. 複製「用戶端 ID」（xxxx.apps.googleusercontent.com）。

## 2. Apps Script（放喺試算表入面）
1. 打開試算表「一夜狼人殺 帳戶紀錄」→ 擴充功能 → Apps Script。
2. 刪除原有內容，貼上 `apps-script/Code.gs` 全部內容。
3. 第 21 行 `CLIENT_ID` 改成第 1 步嘅用戶端 ID。儲存。
4. 上面函式選單揀 `setup` → ▶ 執行 → 授權（揀你自己帳戶 → 進階 → 前往（不安全）→ 允許）。
5. 部署 → 新增部署作業 → 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 部署 → 複製「網頁應用程式網址」（…/exec）。
6. 把網址填入 `src/config.ts` 嘅 `SCRIPT_URL`，重新 build 再 push（或者交俾 Claude）。

之後改咗 Code.gs 要：部署 → 管理部署作業 → ✏️ → 版本「新版本」→ 部署（網址不變）。

## 注意
- 監察只限 Apps Script 擁有者（你）；其他人淨係可以寫入自己嘅紀錄。
- 時間以英國時間記錄。
- 唔好刪除分頁或者改分頁名；改暱稱／勝負可以直接改試算表。
